# आजकल — Vinay's Poetry Website

A minimal, static Hindi poetry website designed for GitHub Pages.

## Publish on GitHub Pages

1. Create a new public GitHub repository, e.g. `aajkal`.
2. Upload `index.html` and `style.css`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will give you a free `github.io` website address.

## Add more poems

Duplicate the `<article class="poem">...</article>` block in `index.html` and replace the title, date, and poem text.

The site uses Google Fonts for typography. It will still work if the fonts cannot load.
